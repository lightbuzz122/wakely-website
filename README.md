# Wakely website

Static site, no build step. Pages: `index.html`, `industries.html`, `results.html`.
Add your sales video as `vsl.mp4` in this folder (keep it under ~50 MB for GitHub, or host it on YouTube/Vimeo/Cloudflare Stream and swap the <video> tag).

## Deploy
1. Upload these files to a new GitHub repository.
2. On vercel.com: Add New → Project → import the repository → Deploy (no settings needed).
